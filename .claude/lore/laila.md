# 秘密の女神ライラ

サルバニの信仰対象。トークで名を唱えさせるときはここを見る。

## 何者か

サルバニの故郷に伝わる多神教の一柱。**秘密を司る女神**。

**サルバニが自分で選んだ神で、親から継いだものではない。** 父は特に信仰していない。詳しくは [sarvani.md](sarvani.md)。

## 唱え方

Skyrim のノルドが「イスミールにかけて！」と言うのと同じ調子で、サルバニは女神の名を唱える。日常の驚きや感嘆にも、改まった誓いにも出る。信心深い土地の言い回しが口癖として身についている、という位置づけ。

確定している形:

```
h1112309ライラにかけて、お預かりした品は
ワタクシが責任をもってお守りいたしまス！
```

```
h1121209ああ、なんと美しい！h1122306ライラにかけて、
この仕事をしていてよかったと心から思いまス。
```

**軽い感嘆としても使える。** 「ライラよ！」「おお、ライラ！」のような短い形は、上のイスミール式という指定から引き出した推測なので、実際に書いて確かめたい。

## 故郷の神々

ライラは多神教の一柱。故郷の名はぼかしたままにしてあり、トークでは「故郷」で通す。いま店を構えているのは日本の伏原で、そちらは [shop.md](shop.md) を見る。

神は必要になったとき随時増やしてよい。**実在の神の名と衝突させない**こと。とくに扉や鍵を司る神は実在の神話に複数いるので、その系統の名は避ける。

| 神 | 司るもの | 出典 |
|---|---|---|
| ライラ | 秘密 | ユーザ設定 |
| トゥエラ | 証文と取引 | 考案。`Lore` の「トゥエラ」と質問「ライラって？」で登場 |

名前のない神も出してよい。質問トークでは「海の神、炉の神、道に迷った者の神」と数だけ示している。

### トゥエラ

交わした約束はすべて書き記し、**必要に応じて**誰にでも見せねばならない、と説く。無条件の開示ではなく、求められたら開くという義務。秘密を守れと言うライラとは折り合いが悪い。

秘密の対になるものを「真実」ではなく開示の義務に置いてある。そのほうが、錠をかけるかどうかという迷いに直に効く。

**故郷の人々は、二柱のあいだで揺れ動くことそのものを楽しみ、尊ぶ。** 商売人は昼はトゥエラ、夜はライラを立てねばならず、たいそう難儀する。その難儀を徳とみなす文化。

サルバニはそこから外れている。

```
h1242309もちろんワタクシは迷いませんがネ！
```

## 書くときに

- 名前を伏せない。「かの女神」のような遠回しは、名前が決まる前の書き方だった
- 説教にしない。サルバニは教義を語る人ではなく、錠に感動したついでに女神の名が出る人
- `Lore`（女神と伝承）の分類はこの設定が本体になる。ただし他の分類でも、感嘆のはずみで名前が出てよい

### ユーザはこの信仰を知らない

**説明の本体は質問トーク「ライラって？」に置いてある**（`events/menu/questions.rs` の `WHO_IS_LAILA`）。掘り下げ選択肢で「どうして鍵屋のあなたが？」「他にも神様がいるの？」まで用意した。

ランダムトークは順不同で出るので、**どれが最初に来ても成立するように書く**。質問を通った前提にしない。初出の語には「秘密を司る女神でス」程度の一言だけ添えて、長い説明は入れない。

## 信仰の形

### 開かずの神殿

故郷にあるライラの神殿。建ってから三百年、一度も扉が開いていない。

何重もの錠がかかり、**その鍵はすべて鋳溶かされている**。そのうえ錠が錠だとわからぬよう、各所に巧妙に隠してある。中に何があるのか誰も知らない。

サルバニはこれを完璧と呼ぶ。開かない箱こそ女神の御身そのものだから。

### 祈りの作法

願い事を紙に書き、錠のかかる箱に入れて閉じる。それで終わり、二度と開けない。口に出した願いはもう秘密ではないので、女神に届くのは閉じたものだけ。

サルバニも十二の年に一つ、故郷の家に置いてきた。**何を書いたかはもう覚えていない。** だからこそ正しく祈りになった、と言う。
