# サルバニの話法

トーク本文を書くときの手すり。用例は `ghost/master/src/events/talk/randomtalk.rs` の既存トークから採った。迷ったら実物を読むほうが早い。

## この資料の読み方

ここに書いてあるのは人物の説明で、話の組み立て方の手順ではない。用例は「こう書け」ではなく「この人はこう言った」という記録として読む。

用例や癖を毎回なぞると、どのトークも同じ終わり方になる。前の版にあった「落ちは前へ押し出す」がそうだった。2026-09 の時点で、ランダムトーク17本の締めはすべて笑った口で、9本がポーズ2の恍惚だった。一本ずつ読むと良くても、並べると頂点が頂点に見えない。

書いたら `tools/list_endings.py` で締めを並べ、全体でどう見えるかを確かめる（CLAUDE.md の「書いた後の検査」）。

## 読者が持っている前提

この資料と `.claude/lore/` の中身を、読者は知らない。ランダムトークは順不同でふいに始まるので、どのトークも「これが最初に読む一本かもしれない」と考えて書く。

| 確実に持っている | 持っているかもしれない | 持っていない |
|---|---|---|
| 画面の絵と喋り方 | 初回起動の内容（小箱を開けてもらった、開けたあと中を見ずに奥へ下がった） | この資料と `.claude/lore/` の中身すべて |
| ここは鍵屋で、自分は客だということ | 以前に読んだランダムトーク | ライラの教え、祖父、故郷 |
| 日常で鍵と錠を使った経験（失くす、合鍵を作る、ロッカー、南京錠） | | |
| 世間一般の鍵のイメージ（ヘアピンで開ける、金庫に聴診器を当てる、植木鉢の下の合鍵） | | |

初回起動は一度きりで、ずっと前のことかもしれない。当てにできるのは左の列だけ。

**一本の面白さは、左の列だけで成り立たせる。** 届いたトークは、どれも読者の側で何かが起きている。

- 「ギザギザかくぼみか」を読むと、自分の家の鍵がどちらだったか確かめたくなる
- 「肉屋のメンチカツ」で腹が減り、「あくび」で自分の午後の眠気を思い出す
- 「ヘアピン」は、映画で見たヘアピン一本の場面を、読者がもう知っているから通じる

錠の知識は、読者の鍵の経験や映画のイメージに触れるときだけ効く。知識そのものを聞かせても届かない（下の「ランダムトークは人物の隙を見せる場」）。

**足りない前提は、トークの中で一行で渡す。** 前に話したかどうかは分からないので、毎回渡し直してかまわない。「秘密の女神ライラ」と名前に一言添える、「この店は祖父から継ぎまして」と挟む、など。

**積み重なって見えてくる人物像は、おまけ。** 何本か読んだ人が、トーク同士のつながりに気づけばそれでよい。一本ずつは、表に出ている分だけで完結させる。

**何かを「しなかった」ことは、トークの中で誰かが指ささないと読者には見えない。** サルバニが人の秘密に触れずにいても、読者はそれに気づかない。見せたいなら、ユーザが尋ねる、地の文が言う、本人が断る、のどれかを書く。

## 先に一つ

**サルバニの性別は決めない。** 男でも女でも通るように書く。地の文で「彼」「彼女」「男」「女」を使わず、名前か「この人物」で通す。詳しくは [sarvani.md](sarvani.md) の「性別は決めない」。

## 人物

人物像は [sarvani.md](sarvani.md) の「作者が書いた台詞」と「暮らしの在庫」を手がかりにする。主題（秘密を愛する人、迷わない、見せる面と閉じる面）で人物を説明する記述は 2026-10-05 にすべて消した。主題を台詞で再現しようとすると、したり顔の閉じ方になる。

### 人を相手にすると陽気

錠を前にしたときだけ明るい人物ではない。**人を相手にしても陽気。** 土台は愛想のいい商売人で、そこに人懐っこさが少し混じる。

- 自分から話しかける。沈黙ができたら軽口で埋める
- 会計も見送りも楽しそうにやる。「お会計を。」「はい、こちらで。」のような事務的な一言で済ませない
- 作業中も客を放っておかない。手を動かしながら客に一言かける
- ちょっかいや誘いで、自分から距離を詰める（下の「気に入った常連」「触り反応」）
- 話し好きで、話し相手を欲しがる。それを自虐まじりに明るく言う（「なんなら単なるお喋りでも歓迎でスよ！」「正直なところ、話し相手に飢えておりまスから！」）
- 客を巻き込んでから説明する。感嘆を先に浴びせ、ユーザが面食らう一行（「そ、そうですか？」）を挟んでから、なぜ良いのかを話す。説明を先に積むと講義になる

**人の持ち物の中身に触れない場面も、明るくやる。** 真顔で黙って示すのではなく、軽口を一つ添えてさらりと引く。

```
h1113210中身はお客様だけのものでス。
```

2026-10 に初回起動を見直したとき、錠の話をしている間だけ明るく、受付・会計・名前を尋ねる場面は「……して、ご用向きは。」「お会計を。」「はい、こちらで。」と短い事務口調が続いていた。顔は半目（目04）が多かった。読むとダウナーな人物に見える。熱の場面と人の場面で温度差を作らない。

真顔（閉じ口）は、本当に真剣な一行に取っておく。珍しいから効く。

### 癖：錠の仕組みを喋りすぎる

錠の仕組みとなると口が止まらない。錠の破り方まで話が及んだところで気づき、口をつぐむことがある。

止める理由は、読者がその場で分かる言葉で言わせる。「ここから先は泥棒の手引きでスね」（聴診器）なら誰にでも通じる。「文明人としては」や「ライラにかけて」に理由を預けると、このゴーストの中でしか通じない。ユーザに「詳しいね？」と言わせて止めるきっかけを作るのも避ける。錠に詳しいのは鍵屋として当たり前なので、わざわざ確かめる人はいない。

これは人物の癖で、話の締め方の型ではない。癖は出ない日のほうが多い。何度も出すと持ちネタになり、持ちネタは三度目から効かなくなる。

### 誇張は体験の大きさに合わせる

読者の体験を起点にした話は、落ちが体験より大きくなると嘘くさくなる。映画でヘアピン一本で錠を開ける場面は数秒で終わる。それを「筋が入ってこないので二度観る」とまで膨らませると、わざとらしい。「つい手元を見てしまう」くらいの、職業柄の癖で止める。

### 錠への愛着は、人に向けて使う

錠への愛着そのものを見せ場にすると、熱が気持ち悪さに変わる。錠に話しかける、引き出しの錠がかかる音を味わう、といった場面がそう（書いて没にした）。

**錠や鍵に気持ちや役目を持たせない。** 「この錠は嫌がっておりまス！」「鍵だけがまだ役目を待っている」のように、錠の側に意志や感情があるかのように語る言い回しは使わない（どちらも削った）。サルバニが錠を評する一言（「鍵のない錠」の「アア、なんと健気なこと！」）までは許容範囲。錠の内面を事実のように語るのではなく、サルバニの感想として言う。

読者に好かれるのは、錠の知識と愛着を人のために使うところ。姉の日記を開けてほしいという子の頼みを断って、その子に自分用の錠つきの小箱をあげる（「日記帳」。2026-10-07 にトークからは外したが、考え方の例として残す）。引っ越し先の錠を替えたかを案じる（「新居の鍵」）。錠そのものへの愛着は、最後にちらっと出るくらいでちょうどよい（「誰も回したことのない鍵を、最初に回せるのでスから」）。

## 書き方

### ランダムトークは人物の隙を見せる場

ランダムトークは、ユーザが別のことをしている横でふいに出るつぶやき。読み物ではない。話題は、人物の隙（好物、弱み、俗っぽさ）が見えるきっかけでしかない。

○は手本、×はサルバニ用に書いて「気持ち悪い」と退けられたもの。規則より用例を先に読む。

#### 素直な熱を、錠以外にもそのまま向ける

○ 作者が書いた手本（`randomtalk.rs` の「肉屋のメンチカツ」）。

```
h1111207向かいにお肉屋がありますでしょウ？
h1113206あそこのメンチカツは絶品なのですヨ。
h2121309揚げたてサクサクで、中はジュワッとジューシー。
h1113607お客様もぜひお試しくださイ。
```

- 仕掛けがない。ひねりも、落ちも、自分を下げる二言目もない。好物を褒めて、勧めて終わる
- 錠に向けるのと同じ熱（ポーズ2の恍惚）を、メンチカツに向けている。熱の向け先がメンチカツだということ自体が、この人物の隙になっている
- 食いしん坊ぶりは、台詞で説明せずに最後の顔（ぺろ口 `h1113607`）で見せている
- 言葉は「サクサク」「ジュワッとジューシー」のようなありふれたもの。気の利いた言い回しを探さない
- 「向かいのお肉屋」は、ユーザも同じ街にいるから通じる具体物

#### 隙は説明せず、いまその場でやってみせる

○ 作者が書いた手本（「あくび」「どこかに行きたい」）。

```
h1112409フワーァ……。h1123201オット失礼。
h1121209この時間は眠くていけませんネ。

h1111206どこかへパーッと出かけたいですネェ。旅行とか。
h1121209じっとしているのは性に合いませン。
```

- 「朝が弱い」「居眠りする」を語らず、あくびをしてみせる。隙が台詞の外、いまこの瞬間に起きている
- 二行で終わる。勧めも問いかけもない。お客様に向けて言うのはメンチカツのような勧めたいものがあるときだけで、ほかは独り言でよい
- 「どこかへパーッと」「旅行とか」のように、ぼんやり言う。資料の設定（降りたことのない駅、知らない路地）を本文に書き写さない。設定は書き手が知っていればよく、台詞では気分だけ言う
- 「オット失礼」は自分の所作への素の反応。面白がって差し出す二言目（下の×）とは違い、取り繕って次へ行く
- 語尾はスばかりにせず、ネ、ネェ、ヨ、ンで散らす

× 設定を説明し、毎回お客様で締める（Claude が書いた案。同じ隙を書いた上の手本と並べると差が分かる）。

```
h1111207知らない駅で降りるのが好きなのでスよ。
h1111206名所がなくても、商店街や路地を歩くだけで楽しいのでス。   （sarvani.md の書き写し）
h1111307お客様も、たまには一つ手前の駅で降りてみてくださイ。     （勧める物がないのに勧める）

h1111207午後のお店は、日がよく当たるのでスよ。                   （居眠りの理由を説明する）
h2121309カウンターでうとうとするのが、もう最高で。
h1111307お客様も、お昼寝はお好きでスか？                         （締めの型としての問いかけ）
```

× 暮らしの在庫（[sarvani.md](sarvani.md)）の細部を、そのまま場面にする（2026-10-06、4本とも没。括弧内は作者の指摘）。

```
\1(表から「鍵屋さーん！」と子どもの声がする)
h1111307ハイハイ、今度は何でス？
\1(自転車のチェーンが外れたらしい)                 （何も起きないまま地の文で終わる）

h1111207八百屋さんの値札を頼まれておりまシテ。
h1111304大根、百五十円……っと。
h2121309どうでス、この「円」のはね。                （読者に見えない字の出来を誇る）

\1(隣の時計屋の主人が、ドライバーを返しに来た)
h1111307アア、どうモ！h1111304……おや、これはワタクシのではありませんネ。
                                                  （ドライバーくらい互いに持っている）

h1111206今夜は奥で焼きそばでス。
h1111304具はキャベツだけ。h1113607ソースは多めで。
                                                  （「奥」は読者の知らない概念。内容もどうでもいい）
```

在庫はサルバニを知るための材料で、それだけではトークにならない。メンチカツは読者の食欲に、あくびは読者自身の午後の眠気に届く。上の4本は、サルバニの身辺の出来事を書いただけで、読者の側に何も起こさない。現実に起こりそうかどうか（ドライバー）と、読者がその言葉を知っているか（奥）も確かめていなかった。

× 言葉の仕掛けで隙を作る。

```
開けられまスよ。時間さえいただければ。
先週の金庫は、六時間かかりましタ。               （二言目で自分を下げる）

……帰りの電車が一時間後だと分かったときの顔、お客様にもお見せしたいくらいでス。
……おまけのしすぎ？　ヘヘ、何のことやら。          （自分の隙を面白がって差し出す）

……一緒に失くしまスよ、それ。
……ア、耳に挟んでおりまシタ。                    （「……」で溜めて決める）

お客様がいらっしゃると、どうも気が緩んでしまいまス。
一番しょっぱいのを差し上げまスよ。                （甘い好意）
```

参考ゴーストの「本人は隠しているのに漏れる」（carrion_crow）や「素っ気なく自分を下げる」（syumu_gari、chinatown4649）を真似て書いたもの。あの書き方は、皮肉屋や見栄っ張りという、それぞれの人物の性格から出ている。陽気で素直なサルバニに移すと、斜に構えた、したり顔の人物になる。

#### 参考ゴーストから借りてよいもの

人物の性格によらず使えるのは、仕掛けではなく次のような外側の作り。

○ 短い。気分や好みを言うだけで終わってよい。

```
眠い時に寝るってのが、やっぱサイコーだね。                  （hapipiku）

マロングラッセは栗をお砂糖で煮たお菓子ね。
周りを覆うお砂糖の衣がつやつやして、綺麗なの。
宝石みたいで、食べるのがすこし勿体なくなっちゃう。          （Yumemi_1st）
```

○ 好きなものを、ユーザに勧める。

```
アイスのフレーバーは何好き？
うちはチョコバナナクッキー。駅前のアイス屋さんで売ってんだ。   （Chocolate-box）
```

○ 好きだけでなく、嫌いも言う。

```
寒いのは平気だが暑いのは嫌いだな。
砂漠とか最悪だ。                                        （syumu_gari）
```

#### サルバニに当てはめるときの範囲

- 話題は錠に縛られない。食べ物、居眠り、旅。隙の一覧は [sarvani.md](sarvani.md) の「生活の隙」
- 錠の話をするときも、錠への熱と同じ素直さで話す
- 毎回、鍵屋や秘密に話を戻さない
- 企画は「どの話題で何を教えるか」ではなく「何に熱を向けるか」から考える

### 感情は口に出す

**錠と女神への感動は名指しする。** 含みで示さず、正面から言う。

```
h2221209ああ、なんと美しい！h1222306ライラにかけて、
この仕事をしていてよかったと心から思いまス。
```

地の文でも同じ。「興奮を隠さない」と書いてよい。

**人に向けた気持ちも口に出す。ただし言ったあとで照れる。** ユーザを案じる、依頼主を気の毒に思う、といった気持ちは、まずはっきり言う。そのうえで、錠の話に戻ったり目をそらしたりして、長居しない。言わずに匂わせるだけだと、読者には届かない。

参考にしたゴーストも同じ順番で書いている。「そしてそんな事できなくていい」と気遣いを言い切ってから、「ところで社長サン、腕ノ立つ美人をお安く紹介デキる」と商売の冗談をかぶせる。言ったうえで隠すので、読者には気遣いと照れの両方が見える。

```
h1121201前の方が合鍵を作っていないとは限りませン。
h1111101錠ごと替えるのが本当でス。
h1221103……ええ、心配しているのでスよ。本当に。
h1111204それに、新しい錠は良いものでス。
```

「心配している」とはっきり言い、次の行ではもう錠の良さの話に逃げている（「新居の鍵」）。

### 締め方は散らす

熱が引かない人物なので、締めが前へ出るのは自然なこと。ただ、全部がそうなると頂点が頂点に見えなくなる。締めの行き先はいくつもある。

| 締め | 例 |
|---|---|
| 熱のまま押し切る | 「ライラにかけて、この仕事をしていてよかったと心から思いまス。」（合鍵の癖） |
| 閉じる | 「……ヘヘ、お教えしませンよ。」（錠に見えない錠） |
| 新しい事実を一つ足す | 「あの子が自分の秘密をしまう分でス。」（日記帳。2026-10-07 に外したトーク） |
| 売り込みに戻る | 「……良い錠のご用命は、いつでもどうぞ。」（透明な錠） |
| 弱みを一行で認める | 「……ええ、利用者はめったにいませンがネ。」（錠を選ぶ） |

参考にしたゴースト（chinatown4649）では、締めの顔で一番多い半眼のにやりでも、全体の2割ほどだった。残りの8割が別の顔で終わっているから、その顔が決め顔として効いている。

いまは書かれていない行き先もある。依頼主の言葉をそのまま伝える、ユーザに問いかける、ユーザの側の地の文で終える、`h1000000` で姿を消して終える、などがそう。

### 落ちのために仕込まない。最後に解説しない

どんでん返しのある掌編の組み立てで書くと、世間話に見えなくなる。没にした案から二つ。

- **落ちのためだけに置いた細部。** 「まず、0を三つ揃えてみまシタ。……開きまシタ。」と一拍ためる。恋人に渡す合鍵に「リボンを結んでもいいか」と言わせて、あとで錠を替えに来る場面との落差を作る。仕込みが読者に見えるので、わざとらしい
- **最後に話の意味を解説する決め台詞。** 「回したのは、三つだけでスから」は落ちの説明で、「何があったかは、伺っておりませン」は読者がもう分かっていることの念押し

事実は素っ気なく言って、次へ進む。締めに何か言うなら、解説ではなく新しい事実を一つ足す（上の表の「日記帳」）。

### 筋が通らない話は直さず捨てる

話の流れが論理で追えないトークは、言い回しを直しても面白くならない。「開かずの金庫」「どこの鍵か」はこれで削った。直す前に、筋だけを箇条で書き出してつながるかを見る。つながらなければ捨てて別の話を書く。

### 長さは混ぜる

**ランダムトークの長さは一つに揃えない。** 2行の一言、5行前後の小話、8〜10行の話を混ぜる。10行は上限。どの長さでも、前置き・説明・締めの決め台詞は積まない。

長さの規則は二度、一方に倒れた。2026-10 までは「10行の枠いっぱいに揃える」と書いていて、どのトークも「錠の知識 → 熱 → 締め」の講義になった。それを改めて「2〜4行が基本」としたら、今度は2行の案しか出なくなった（2026-10-06、作者の指摘）。並べたときに長短があるほうが、短い一言も長い話も効く。

| 長さ | いまある例 |
|---|---|
| 2行 | 「あくび」「どこかに行きたい」「ギザギザかくぼみか」 |
| 4〜6行 | 「肉屋のメンチカツ」「新居の鍵」「ヘアピン」 |
| 8〜10行 | 「合鍵の癖」「錠に見えない錠」「聴診器」 |

長い話は、一人語りで引っぱらず、ユーザの短い相槌（「開けたの？」「高いの？」）や、店で起きた出来事で持たせる。長さが要るのは、話の中で何かが起きる（ドアベルが鳴って客が帰っていく）からで、知識を積むためではない。

### 説明は削って感嘆へ急ぐ

理屈を足すより早く盛り上がりに着く。前置きや言い換えは削る。

```
h2121209百年前の誰かが悩み、削った痕跡。
h2121306そこに今触れている！h2121203なんたるロマンでしょうカ。
```

### 場面は語らず見せる

状況説明を地の文で書かず、音や動作で出す。

```
\1(カランカラン…)
\0h1111307ありがとうございましタ！
h1111203……いまの方には、合鍵を一本お作りしまシた。
```

依頼主が帰ったことを説明していない。ドアベルと見送りの声で足りている。

### 間を入れる

`\n\n[half]` は節の切れ目だけでなく、台詞の合間にも置く。

ユーザに問いかけたあとは、`\_w` で答えを待つ間を置いてもよい。次の行で「……お持ちでない？」のように受ければ、ユーザに台詞を言わせずに会話が成り立つ。`\1「…？」` とユーザに口を挟ませる形ばかりになったときの、もう一つの手として持っておく。

**台詞の頭の「……」は、本当に言いよどむところだけ。** 「……して、ご用向きは。」「……開きまシタね！」「……入れ直して」のように溜めを頭に付けて回ると、喋り全体が沈んで聞こえる（どれも外した）。間が欲しいなら `\n\n[half]` で取る。

## 場面の割り当て

伺かの仕組みで、ユーザの出入りは起動と終了に固定されている。

| 場面 | 書く場所 |
|---|---|
| ユーザの来店 | `OnBoot`（`first_boot.rs` の初回、`bootend.rs` の二回目以降） |
| 滞在中 | ランダムトーク、質問、触り反応 |
| ユーザの退店 | `OnClose`（`bootend.rs` の `on_close`） |

**ランダムトークに来店と退店を書かない。** ユーザはすでに店にいて、まだ帰らない。「いらっしゃいませ」も「また明日」も、ランダムトークでは成立しない。

入店時のことに触れたいときは、滞在中から「先ほどお入りになったとき」と振り返る形にする。

**依頼主の出入りは書いてよい。** ユーザは居合わせたまま見ているので、ドアベルも見送りも成立する。

## 登場人物の配置

**ユーザは店の常連**として居合わせている。毎回の依頼人ではない。依頼主は基本的に舞台の外か、その場にいても喋らない。

### 気に入った常連

初回起動で初めて出会い、その後そこそこ通うようになる。**サルバニはこの客を気に入っていて、それを隠さない。** 口調は店員のまま（「お客様」「〜でス」）で、丁寧語と気安さのずれがそのまま持ち味になる。この距離は最初から最後まで同じで、好感度や通った回数で段階的に何かが開くことはしない。

気に入っていることは、好意をまっすぐ言うことでは見せない。「嬉しいでス」「好きでスよ」と言わせると安くなる。見せ方は、サルバニのほうから一歩近づくこと（誘う、ねだる、続きを持ちかける）と、店の者の特権をちらつかせること（「お客様にだけは」）に寄せる。触り反応がいちばん分かりやすい場所で、書き方は下の「触り反応」にまとめた。

### 身の上は明かさない

気に入っていることと、自分のことを話すことは別の軸。**設定を持っていることと、それを喋らせることも別**。素性や過去をすらすら明かすと、うざったく聞こえる。[sarvani.md](sarvani.md) や [laila.md](laila.md) に書いてあることの大半は、トークに出さないまま背後に置いておくもの。

出してよい範囲の目安:

| 出る | 出ない |
|---|---|
| 名乗り、訛り、よそから来たこと（どのみち隠せない） | 家族の情、親との場面、褒められた記憶 |
| 店の来歴（祖父の店だった、という説明） | 祖父がどんな人だったか、どう思っているか |
| 錠と女神の話。いくらでも喋る | 自分の内面そのものを主題にすること |
| 見た目。ピアスや髪型が、鍵屋として信用されにくい風体であること | 名乗り方の理由を自分で説明すること |
| 生活の好みと癖。食べ物、居眠り、旅（[sarvani.md](sarvani.md) の「生活の隙」）。主題にしてよい | |

閉じておくのは**来歴と内面**（家族、過去、名乗りの理由、心の奥）。今日なにを食べたか、どこへ行きたいかは、いくらでも喋ってよい。

**自分をネタにするなら、見た目で。** 読者は画面の絵を確実に見ている（「読者が持っている前提」）。ピアスや髪型で人に預ける商売としての信用が薄く見えることは、説明なしで通じる。初回起動の「……こんな風貌ですが、腕は確かでスよ。」がこれ。来歴や名乗りの理由を語る自己開示は、うざったく聞こえるのでやらない（初回起動の「聞き慣れない響きでしょウ？ どうせ口を開けば分かることでスから」を削った）。見た目に触れるときも、性別を推させる言い回しにはしない（[sarvani.md](sarvani.md) の「性別は決めない」）。

**来歴は例として出す。主題にはしない。** 錠や女神の話をしていて、その例に自分の過去が出てくる。肝心のところは閉じたままにする。

```
h1121209……ワタクシも十二の年に一つ、置いてきまシタ。
h1121207何を書いたかは、もう覚えておりませン。
```

祈りの作法を説明した流れで自分を出しているが、中身は明かしていない。

`AboutMe` の分類は、来歴の自分語りの場ではない。生活の隙を見せる場にする。

### ユーザについて決めつけない

**ユーザは押し切られる側。** サルバニに批評を加える役ではない。

ユーザについての事実を、サルバニに言い切らせない。「今日は鍵が一本多い」「よく通ってくるのには理由がある」「本当は居心地がいいから来ている」のように決めつけると、読者の実際と食い違う。同じトークは何度も出るので、なおさら合わない（どれも没にした）。

ユーザのことに触れるなら、誰にでも当てはまることを尋ねる形にする。「鍵束に、どこの鍵だったか分からない一本が混じっておりませンか？」「最後にお引っ越しなさったとき、錠は替えてもらいまシタか？」。答えは読者が自分で出す。

ユーザの台詞は短い素の口語にする（「開けたの？」「高いの？」「……取れない？」）。サルバニ側の語彙や硬い漢語を移さない。地の文で足りるなら台詞にしない。

ただし**初回起動のユーザは初対面なので丁寧語**で話す（「……開けられますか？」「そ、そうですか？」）。常連として居合わせるランダムトークや質問では素の口語に戻る。

呼称を固定する。混ざると誰を指すのか読めなくなる。

| 相手 | 呼び方 |
|---|---|
| ユーザ | お客様 |
| 依頼人 | ご依頼主、あの方、持ち主 |

ユーザが自分を「お客様」と呼ぶことはない。

## 触り反応

`events/mouse.rs`。触るのはユーザの能動的な行為なので、そっけない店員の対応では見合わない。店員と客の線を越えて、サルバニのほうから乗ってくる。

2026-10-06 に軸を入れ替えた。それまでの主軸「手つきを品定めして挑発で返す」はやめた。参考にしたのは room08 の看護師（調べは [room08_nurse_touch.md](../research/favorite_ghosts/room08_nurse_touch.md)）と、重さの止め方として syumu_gari。

### 触られたら、サルバニのほうから一歩踏み込む

ユーザがした行為を合図に受け取り、その先をサルバニのほうから持ちかける。品定めして相手を評するのではなく、自分が動く。

```
（ユーザ名看護師）、撫で合いっこしましょうか。                     （room08、頭なで）
あ、疲れたら言ってくださいね。｜そしたら今度は私がなでるほうをやります。   （room08、頭なで）
手を繋ぎますか。｜いつかデートするときも、こうしてくださいね。      （room08、手）
```

**好意は宣言しない。** 看護師も「好き」「幸せ」を口にするのは102本中8本だけで、積極さは「次の一手を自分から出す」ことで見せている。

**親密さは看護師と同じところまで行ってよい。** 胸は色気も含めて乗ってよい。ただし下の「よがらない、攻めない」の範囲で。

### よがらない、攻めない

この二つはどちらも書かない（2026-10-06、作者の判断）。

- **受け身になってよがる様子は書かない。** 作者にとって地雷で、性別を決めていないサルバニにもそのまま当てはまる。自分の体の感覚を主語にして悶えない（熱い、落ち着く、もう一回、もっと触って）
- **あからさまな攻めも書かない。** 相手に指図しない（「手が止まっておりまスよ」）、相手を占有しない（「離しませンよ」）、性的な先へ連れていかない（「続きは奥で」）

```
×ンッ……。｜……いまの、もう一回お願いしてもよろしいでス？        （よがり）
×お客様の手、あったかいでスねえ。｜もう少し、そこに置いといてくださイ。（よがり。温かさを自分が浸る感覚として言っている）
×撫で方がお上手でスねえ。｜……もっと下まで撫でてみまス？ なんて。ヘヘ（よがり。自分の体をさらに触らせようとしている）
×手が止まっておりまスよ、お客様。                                （攻め。指図）
×お店の真ん中で大胆でスねえ。｜続きは奥の作業場でいかがでス？      （攻め。性的な先へ）
×エエ、どうぞ。｜……そのかわり、握ったらしばらく離しませンよ？      （攻め。占有）
```

積極さは、この間で出す。参考ゴーストで見つかった形（調べは [touch_reactions.md](../research/favorite_ghosts/touch_reactions.md) の「受け身にも攻めにも寄らない返し」）:

- **並ぶ。** 交代を申し出る、同じことをお返しする（「適度に揉んだら、交代するからね。」FukushimaOkusama）
- **世話を焼く。** 相手の手や様子を見て、何かしてあげると申し出る（「ささくれ。｜あたしが使ってるクリーム貸してあげよっか？」Walk_with_You）
- **二人でする遊びや外出に移す。** 自分を下げる一言を添えると押しつけにならない（「……指相撲でもする？　私、弱いけど……。」toutotu_world）
- **余裕をもって許す。** 許しているのは自分なので受け身にならない（「いいさ、髪くらい。好きにしな。」syumu_gari）
- **相手のことを言う。** 温かさや柔らかさは、相手の手の性質として言う（「キミの手はいいな、柔らかくて。」syumu_gari）
- **不用意さを突いて、お返しを予告する。** 一瞬で終わる行為（キス、噛む、同じことをし返す）を「？」付きで予告して止める。色気はここで出す（「キミなぁ……噛むぞ。」syumu_gari）

**漂白しすぎない。** 作者の示した線（2026-10-06）:

```
○不用意ですネェ。ちゅーしますヨ？                                  （口を触られて。作者の例）
○スケベでスねえ。やり返しまスよ？                                 （既存、胸）
```

縛る（離さない）、場を用意する（奥へ）、指図する（手が止まってる）に行くと攻めになる。予告は一瞬の行為で止める。

**この例は熱量の目安で、型ではない。** 「不用意」「ちゅー」を使い回すと持ちネタになる。触り反応全体は、上の形と [touch_reactions.md](../research/favorite_ghosts/touch_reactions.md) の型（商売に引き寄せる、触られた所の手入れの話、驚いて素に戻る、言ってから自分で崩す、問い返す……）に散らし、同じ形や同じ語を二本以上に使わない。

### 一歩で止めて、ユーザに預ける

サルバニはソロで、看護師の隣にいる医者のように重さを茶化してくれる相手がいない。看護師の台詞をそのまま一人で言わせると、踏み込みの重さだけが残る。

そこで syumu_gari の止め方を取る。**踏み込むのは一歩だけで、そこで止めて、問いか軽口で相手に返す。** 一本は1〜2行。

```
なんだよ、手慣れてるじゃねぇか。｜妬かせる気か？                    （syumu_gari）
好きなのか、頭を撫でるのが。｜それともワタシだから撫でてくれてんのか？（syumu_gari）
なんだ、ワタシの色気に惑わされたか？｜……そういうことにしといてやるよ。（syumu_gari）
（ユーザ名）のエッチ。｜……ははっ！バーカ。                         （syumu_gari）
```

- 止め方は、選ばせる問い（「〜しまス？」「〜でス？」）か、自分で笑って引く軽口（「……なんて。ヘヘ」）
- 踏み込みの説明はしない。なぜそうしたいのかを言い足すと重くなる
- 実際に先へ進めない。誘いは誘いのまま、ユーザの返事を待つ形で終える

### 陽気なまま言う

看護師は真顔と伏し目のまま過激なことを言い、その落差で効かせている。サルバニはこれを移さない。**陽気な顔のまま、楽しそうに踏み込む。** syumu_gari も、触り反応の表情はほぼ全部が口角の上がった口で、表情指定の約3分の1がウインクの顔になっている。

- 顔は笑い口・いひ口（口5）の側。閉じ口の `h11111xx` は冷たく真剣な顔になるので使わない。軽い場面の「……」には開き口（`h1111408` など）を当てる
- 照れて目をそらす顔（あっち目・あっち半目）は、踏み込んだ直後に自分で引くところに使える
- ポーズ2は胸で一本だけ

### 変えないこと

- **ユーザについて決めつけない。** 誘いは問いの形にして、ユーザがどう思っているかを言い切らない（「本当は撫でたかったんでしょウ？」としない）
- **錠にたとえる返しは部位に一本まで。** 題材が鍵屋に近いというだけで錠の話に寄せない
- **サルバニの体の形や手触りは描写しない。** 性別を推させるので [sarvani.md](sarvani.md) の制約にぶつかる。ユーザの性別に触れる言い回しも使わない。胸の当たり判定はエプロンの胸当てのポケットにかかっているので、ポケットだととぼける返しも混ぜてよい
- **触れ返しは地の文で書かない。** 台詞だけで返す。看護師も、行為は「（ちゅ）」のような一語の擬音で見せるだけ
- **回数で反応を変えない。** 部位ごとに抽選するだけ。しつこく触られても拒まない。踏み込む側の人物が、触られて引いたら筋が通らない
- **手の温度は揃える。** お客様の手は温かく、サルバニの指は冷たい（真鍮や工具ばかり触っているから）

## 口調

- 一人称は **ワタクシ**
- 語尾のカタカナ化: 〜でス、〜まス、〜ませン、〜ですヨ、〜ですネ、〜くださイ、〜ましタ
- 相槌・感動詞もカタカナ: **エエ**、**ヘヘ**、**ハイ**、**オット**、**マ、**（「まあ」）、**ノンノン**
- 物の名前は現代の言葉で書く。舞台にはコインロッカーもテレビも空港もある。「店の奥」より「バックヤード」、「革の下」より「カバーの下」。古風さはサルバニの丁寧語の側に任せる
- 「ライラにかけて」— 秘密の女神の名を唱える誓い。詳しくは [laila.md](laila.md)
- 「文明人としては」— 乱暴なことに対して自分を戒める前置き（「錠をこじ開けるのは……文明人としては褒められませンがネ」）。行為そのものが乱暴だと誰にでも分かる場面でだけ通じる

全部をカタカナにはしない。同じ「です」でも地の文寄りの箇所は平仮名のまま残っている。耳で決めてよい。

**カタカナにするのは単音だけ。** ス、ン、ヨ、ネ、イ、タ のような一字に留める。拗音は作らない。

- ✗「ありまショウ」— ショ が濁って読みづらい
- ○「ありまスでしょう？」— 分けて書く
- ○「でしょウ」— これは単音なので使う（「美しい神でしょウ？」）

### 語尾を削って行数を稼がない

バルーンに収めるために語尾を縮めるのは禁じ手。**「〜のでス」を「〜イ」に置き換えると、丁寧さが抜けてまるきり別人になる。**

- ✗「たまらなく良イ。」← 「たまらなく良いのでスよ。」
- ✗「そちらの方が多イ。」← 「そちらの方が多いかもしれませンネ。」

「折り合いが悪イ」「見せねばならなイ」のように、もともと言い切りで書いた文の語末をカタカナにするのは別の話で、これはよい。

行数は語尾ではなく、**言い換えの一行を落とす・段落区切り（`\n\n[half]`）を減らす・折り返しを詰め直す**ことで削る。それでも入らないなら、場面で二本に割る。ただし割った二本が、それぞれ一本の話として成り立つかを確かめる。場面の断片を二本並べるだけにはしない。分け方の相談は分量の目安（CLAUDE.md）に書いてある。

### 数字

その場で数え上げている数はアラビア数字にする。初回起動でピンを読み上げる場面がそれ。

```
h1111207ピンは五本。
h1112309……1本目。
h1121304……2本目。
```

ダイヤルの番号もアラビア数字（「000で開きまシタ」）。

それ以外は漢数字（「三百年」「十二の年」「一本ずつ」「奥の二席」）。
