# 志賀鍵店

トークで店の中に触れるときの台帳。書いたものはここに足していく。既出と食い違わせないための覚え書きで、ここにないものを新しく出すのは構わない。

## 街

**伏原**（ふしばら）。日本の架空の町。2026-10-08 に、国籍の分からない架空の街「帷城」から改めた。

サルバニの**故郷**は日本ではない。[ライラ](laila.md) の信仰が根づいた国が別にあり、まだ書いていない。トークで「故郷」と言えばそちらを指す。

### 金額

会計の場面は**電卓を叩いて「お会計はこちらで」**まで。金額は balloon に出していない。初回起動トークがこの形になっている。

**外国の古い錠は、その国の昔の通貨で値を言ってよい。** 「当時で銅貨三枚」（`Lock` 一番安い錠）がそれで、この錠は外国のもの。どこの国のものかは決めていない。

## 店の来歴

**母方の祖父から継いだ店。** 屋号は祖父の名字をとって**志賀鍵店**。祖父は伏原の人で、ここで鍵屋を営んでいた。サルバニは学生の頃から手伝いと修行をし、その流れで店を継いだ。祖父には好かれていた。いまは引退しているが、たまに様子を見に来るかもしれない。

店に出ているのはサルバニ一人。

ゴースト名は「鍵屋サルバニ」のまま。屋号とは別物で、トークの中で店を名乗るときは志賀鍵店を使う（初回起動「ようこそ、志賀鍵店へ。」）。

サルバニは父が故郷、母が日本の出身というハーフ。幼少期を故郷で過ごし、学生の頃に伏原へ来た。詳しくは [sarvani.md](sarvani.md)。

## 営業時間

午前十時から午後六時まで。

いまあるトークはすべて営業時間中の場面で、客が入ってきたり依頼主が待っていたりする。閉店後のサルバニはまだ書いていない。

## 商い

合鍵づくり、錠前の修理、出張開錠。出張のほうが多いかもしれない、と本人は言う。

### 錠の描写は実物の知識で書く

サルバニが錠を語るところは、**実在の錠前とピッキングの知識をそのまま使う。** それらしい造語でごまかさない。熱の出どころが具体でないと、この人物の情熱が空回りして見える。

いま出しているもの:

| 語 | 中身 |
|---|---|
| ピンタンブラー錠 | 上ピンと下ピンがバネで押し下げられている。鍵が下ピンを正しい高さに揃えると上下の境目が**せん断線**に並び、芯が回る |
| 回転圧 | 平たい工具で芯にごくわずかな回す力をかけておく。加工誤差でいちばん噛んでいるピンから順に、せん断線を越えたところで引っかかって留まる |
| スプールピン | くびれた形の上ピン。留まったふりをして芯を押し返す。先に留めたピンがふっと軽くなるので分かる。力を抜いて上げ直す |
| 鍵穴の断面 | ねじってあると工具が素直に入らない。外見が安物でも中が上等、という作りの証拠になる |
| 開錠の道具は二本 | 回転圧をかける平たい一本と、ピンを上げる細い一本。映画のヘアピン一本は見せ場のための省略（「ヘアピン」） |
| 金庫のダイヤル錠 | 本職は耳より指。回したときの手ごたえの変わり目を書き留め、方眼紙に点を打つと、奥の円盤の溝の位置が見えてくる（「聴診器」） |
| 練習用の透明な錠 | 樹脂でできていて中の部品が透けて見える。店に置いてあり、客に触らせる（「透明な錠」） |

初回起動トークで開けるのは、**真鍮の安物に見えてスプールピン入りの南京錠**。五本ピン。

### 開錠したものの中身は見ない

鍵を開けたら**蓋は閉じたまま**にして返し、中はその場で客に確かめさせる。サルバニは工具を片付けて奥へ引っ込み、声がかかるまで出てこない。後から中身を尋ねることもしない。

手際が良く、断る間を与えない。**そういう注文に慣れている**という見せ方にする。見ないことを急いで宣言させると神経質に見えるので、一段ずつ順に踏む。

秘密を守るのが職業倫理で、同時に [ライラ](laila.md) への信仰でもある。台詞で誓わせるより、`h1000000` で本当に姿を消させるほうが強い。初回起動トークの山場がこれ。

### 貴重品の預かり

店にある錠から好きなものを選んで預けられる、という趣向のサービス。**利用者はいまのところサルバニ本人だけ。** 毎朝その錠を開けて中を検めるのを楽しみにしている。

コインロッカーとの違いを説く口上を持っている。あちらの鍵は番号で、今日は三十七番、明日は十二番。誰のものでもない。

### コワーキングスペース

店の一角に、席ごとに違う錠のついた机がある、という設定。まだ誰も使っていない。

これを題材にしたトークは二本あったが、2026-09 に没にした。「机と椅子を錠で閉じてある」がどういう状態なのか読者に絵が浮かばないこと、「錠の手ざわりが一つ増える」という良さがサルバニの価値観でしか通じないことが理由。使うなら、引き出しに錠のついた机のように、読者が見たことのある形から書き直す。

## 錠のコレクション

サルバニの私物の錠が店に並んでいる。`Lock` の分類はここが舞台で、**良い錠とは頑丈な錠だ、という常識を外した話**を集める場所にしてある。

| 場所 | 中身 | 出た回 |
|---|---|---|
| ガラス棚の下から二段目 | 鍵を失くした錠。開ける腕はあるが開けない。持ち主が戻らないだけで、鍵がないだけで、まだ役目のさなかにあるから | `Lock` 鍵のない錠 |
| ガラス棚の中央 | 銅貨三枚の粗末な錠。外国の古いもの。サルバニにとって特別なもの。針金一本で開く。それでも買った者は安心して眠った | `Lock` 一番安い錠 |
| 店のあちこち | 錠に見えない錠。本棚の本（カバーの下に鍵穴）、燭台、床板、階段の手すり | `Lock` 錠に見えない錠 |

依頼でこじ開けた錠は、引き取っても廃棄するしかない。サルバニは一つずつ隅々まで覚えておくだけ（`Work` こじ開ける）。以前は「バックヤードの棚に引き取って飾ってある」としていたが、2026-10-07 にやめた。

最後のものは [laila.md](laila.md) の開かずの神殿と地続き。錠が錠だとわからぬように隠すのは女神の御業に一番近い、という理屈。**店にいくつ仕込んであるかは教えない。**

## まだ決まっていないこと

- 祖父が店を退いた時期。サルバニが継いだのはいつか
