## サルバニに関係すること（要点）

1. **長さは1〜2行が普通。** ほぼ全ゴーストで中央値が1〜2行。3行を超えるのは、コンビで相方が口を挟むもの（Walk_with_You、room08、twelfth_night、suisou、fulloflove_desuwa）と、小噺にする HighColorMulti だけ
2. **部位は中央値で7前後、1部位に3〜20本。** 多いのは頭・胸・手・顔・髪・脚・尻。サルバニの当たり判定は頭・胸・肩・手の4つ
3. **ソロでいちばん広く使われているのは「触られた所の手入れや持ち物の話」**（下の T3）。触った場所をきっかけに、生活の細部を一つ出す
4. **chinatown4649（サルバニにいちばん近い売り子）は、102本のうち18本で店の人の立場に引き寄せている**（値引き、売り込み、ツケ、売り物じゃない）。どの部位にも1〜2本ずつ散らしてあり、固まっていない（T2）
5. **回数で反応を変えるゴーストは半数を超える**（31/51）。ただし多くは目に見えない好感度の加減算。目に見える形は「初回だけ別」「短い間に続けると段階が進む」「しつこさが閾値を超えると態度が変わる」の三つ

## 仕組み

### 里々のイベントと節の名前

里々は `OnMouseDoubleClick` を `＊(スコープ)(当たり判定名)つつかれ` に、撫で（同じ場所への `OnMouseMove` が `＄なでられ反応回数` を超えたとき）を `＊…なでられ` に、ホイールを `＊…ころころ` に振る（里々 docs「デフォルトの動作」）。当たり判定のない所は `＊0つつかれ`。

多くのゴーストは触りの節を `＞頭なでられトーク` のような振り分けにして、本文を名前つき節か単語群（`＠頭なでられセリフ`）に置く。単語群に書くと1行1本になり、本数が増えやすい（syumu_gari、zizezo、rabi、SilentBisque）。

### ダブルクリックとメニュー

- **当たり判定のない所のダブルクリックはメニュー**。ほぼ全部がこう
- **部位のダブルクリックをメニューや話しかけに回すもの**: FukushimaOkusama と AbunaiMONAMOUR は肩→「話を振る」、whitelion は頭→メニュー、owl はスカート→メニュー、Walk_with_You は頭→トークメニュー
- **一言返してからメニュー**: chinatown はシニョンと裾のダブルクリックで一言言ってからメニューを出す。裾を引かれたのを呼び止めと受け取る（「照れ屋なガキみたいな呼び方するネェ。」「ハイハイ、お聞きしますヨ～～。」）

サルバニの「肩を叩かれたら一言返してメニュー」は、この最後の形と同じ。

## 受け身にも攻めにも寄らない返し

2026-10-06 に作者から、触り反応で次の二つを避けたいと言われた。そのうえで、間にある返し方を参考ゴーストから拾い直した。

- **受け身になってよがる様子**（作者にとって地雷。サルバニは男性とは限らないが、その要素も持つ）
- **あからさまな攻め気**

### 両端の例

```
（受け身のよがり）
やだよお（ユーザ名）、もう許してよう……！                        （vii）
……体が、熱く、なって……                                         （konno_chang）
（ユーザ名）の手、落ち着く…。                                    （sagiri_tama）

（あからさまな攻め）
仕方のないヒトデスネェ。｜押し倒されてアゲちゃおっカナァ            （room08 の医者）
おいキミ、次は私の番だろ？｜ほらどうしたさっさと服を脱ぐんだ。      （Katari）
```

受け身のよがりは、**自分の体の感覚を主語にして**悶える（熱い、落ち着く、許して）。攻めは、**相手に指図する、相手を占有する、場を用意して性的な先へ連れていく**（脱げ、離さない、続きは奥で）。

**漂白しすぎない。** 作者は、口を触られて「不用意ですネェ。ちゅーしますヨ？」くらいは言わせてよいとした（2026-10-06）。ユーザの不用意さを突いて、キスや噛みつきのような軽い一瞬の行為を「？」付きで予告するのは、攻めに入らない（下の M6）。

参考ゴーストで男性の人物が触られる場面は少ない。room08 の医者（\0）はほぼ全部が攻めの側で、作者の避けたい形そのもの。appletree のオドラデク（\1）は脈絡のないギャグを返すだけ。性別のない人物として書かれている whitelion のリンドウは、驚く・心配する・困る、で返していて、よがりも攻めもない（「どういう反応がいいのか分からないだけ。好きにしてくれ……」）。

### 間にある返し方

**M1. 並ぶ（交代・お返し）。** 相手にされたことを、同じ高さでやり返すか、交代を申し出る。遊びの調子のまま。

```

……やりましたね？｜（ユーザ名）さんの足にも、お返しです。ふふ。     （konno_chang）
```

room08 の看護師の「撫で合いっこしましょうか」「疲れたら言ってくださいね。そしたら今度は私がなでるほうをやります」もこれ。看護師の台詞のうち、攻めに寄らずに積極的なのはこの型が多い。

**M2. 世話を焼く。** 触った相手の手や様子を見て、何かしてあげると申し出る。積極さが、相手のためになる行為に向く。

```

あらあら、爪が伸びていますわね（ユーザ名ちゃん）。｜後でワタクシに爪切りさせて下さいましね。   （fulloflove_desuwa、手）
お父様の手、カサカサね。｜ハンドクリームを持ってきてあげるわ。                    （kaiyagura、手）
お前の手はまだ冷たいな。｜我の手で温めてやろう。                                   （Mantodea、手）
```

手の当たり判定で多い。

**M3. 二人でする遊びや外出に移す。** 触りを、性的でない別の行為への誘いに変える。誘いは軽く、答えは相手に預ける。

```
どこか連れてってくれるカ？｜絶対ワタシの方がこの街詳しいだけど。    （chinatown4649、手）
……ヒマか？｜……指相撲でもする？　私、弱いけど……。               （toutotu_world、手）
何なら繋いで帰ったりする？｜別にええよ、なんか聞かれたらちゃんと説明すればええだけやし。   （zizezo、手）
暇なら手遊びでもしようか？　アルプス一万尺とか。                    （suisou のマリア）
```

自分を下げる一言（「私、弱いけど」「絶対ワタシの方が詳しい」）で、誘いが押しつけにならない。

**M4. 余裕をもって許す。** 触られたのを、上から鷹揚に受け入れる。許しているのは自分なので受け身にならず、何も要求しないので攻めにもならない。

```
いいさ、髪くらい。｜好きにしな。                                  （syumu_gari）
キミだから許してるんだぜ？わかってんのか。                          （syumu_gari）
甘やかしたいのか？　いいぞ。                                       （suisou のマリア）
レディの髪を許可なく触るなんて…。｜…あなただけは、特別に許してあげるけれど。   （Dismember）
```

「もっと撫でていいぞ」（gingitune）まで行くと、ねだる側に寄る。

**M5. 相手のことを言う。** 自分がどう感じたかでなく、相手の手や手つきのことを言う。

```
キミの手はいいな、柔らかくて。                                     （syumu_gari）
やわくて細いねえ、（ユーザ名）さんの手。｜水仕事とかさせるの申し訳なくなるな。   （Walk_with_You の葵）
何回人生やり直したら｜そんなスッと他人の手ぇ取れるようになるんだろうな……。      （toutotu_world）
```

「あったかい」「落ち着く」を自分の側の感覚として言うと、受け身のよがりに寄る（sagiri_tama の例）。相手の手の性質として言うと寄らない。

**M6. 不用意さを突いて、お返しを予告する。** 触ってきたのは相手なので、こちらは返すだけ。返すのはキス・噛む・同じことをする、のような一瞬で終わる行為で、実際にはやらず「？」で止める。色気はここで出せる。

```
んだよ、キスでもしてぇのか。                                       （syumu_gari、口）
キミなぁ……噛むぞ。                                                 （syumu_gari、口）
気軽に触るじゃねぇか。｜てことはだなキミ、自分がされたって文句は言えねぇだろ。なあ？   （syumu_gari、胸）
噛まれたいノ？｜困ったお客さんネ～～。                              （chinatown4649、口）
……あんまりその気にさせたら頂いちゃいますよ？                       （maidSM、胸）
呼んだだけとか言ったら、かわいすぎて押し倒しますね。                 （room08 の看護師、頬）
```

予告が縛る方向（離さない）や、場を用意する方向（奥へ）に行くと攻めになる。サルバニの既存の「スケベでスねえ。やり返しまスよ？」はこの型。

## 非言語の面

- **表情の二段**: 1本で2回以上表情を変えるものが4割前後（数え方は下）。T4 の「驚き→素」のほか、問いかけの行で目を細める（syumu_gari の挑発は行ごとに番号を変える）。chinatown は驚き用の顔（1200番台：目見開き・眉通常・口横開き）、尻を叩かれたとき用の顔（1500）、スカートめくり成功用の顔（1600番台）を、触り反応でしか使っていない
- **間**: 「…」を含む本が2〜4割（NotofThisWorld は87%）。DSLGS と Lilacram は、台詞の前に「…ｗ９…ｗ９」を挟んでから一言言う。間を置いてから素っ気なく言うと、触られたのを流しているように見える
- **擬音の括弧**: 「(ぽよん)」（chinatown）、「(むんず)」（Lilacram）、「(べしぃっ！)」「(ぽふ)」（zizezo）。地の文を書かずに、何が起きたかを一語で見せる
- **呼び方**: chinatown は普段「お客サン」、咎めるときだけ名前（上の要点8）。zizezo は3割強の本でユーザを名前で呼び、からかいの問いに添える（「やってて楽しいん？　（ユーザ呼称）は。」）
- **ユーザの感覚を書く地の文**: 「（いいにおいがする）」（AbunaiMONAMOUR）、「（女の子の胸を撫でているつもりなのに、何故かフワフワした羽毛を撫でているような気がした）」（owl）、「φ（女王の髪は新緑の香がするφ）」（Mantodea。頭を触るとこれだけ返る本が多い）。触った側の手が何を感じたかを書く
