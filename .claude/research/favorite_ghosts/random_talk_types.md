# ランダムトークの型

**これを手本にしてトークを書かない。** 型の名前に分けた時点で、各ゴーストの台詞が生きていた理由（作者がその人物の暮らしを知っているから出てくる細部）は抜け落ちている。型とサルバニの設定を掛け合わせて書くと、設定を言い換えただけの台詞になった（2026-10-05）。ここは調査の記録として読む。トークの種はサルバニの暮らしの具体物から取る（[sarvani.md](../../lore/sarvani.md) の「暮らしの在庫」）。

参考ゴーストのランダムトークを、作りの違いで分けた。分類は [classification.md](classification.md)。用例は短く切って引いている（ウェイトは省いた。「｜」は話者の交代）。

サルバニがいま持っている型は二つ。

- **長め**: 錠の知識 → 熱 → 締め、8〜10行。以前の規則で書いたもの（`Work`、`Lore`、`Lock`、`WithYou`）
- **短い独白**: 2行前後。好物を褒める、あくびをしてみせる（`AboutMe` の「肉屋のメンチカツ」「あくび」など）

「サルバニに」の欄は、○がそのまま使える、△が条件つき、×が合わない。

## ソロの型

### S1. 好き嫌いを一言

```
甘いもの食べて「甘すぎなくていい」って言うの、おかしくない？
ないでしょ。甘すぎることなんて。                        （Chocolate-box）
```

Chocolate-box、syumu_gari、soine、gingitune、hapipiku。ソロでいちばん多い。
**サルバニに: ○（済）**。「肉屋のメンチカツ」「どこかに行きたい」がこれ。

### S2. その場で起きたことを実況する

```
（－１）あいて！
（４）いてぇ～……。またぶつけたぁ。
ウチの店、背の低い子が多くて、つっぱり棒とかぜ～んぶ低いとこにつけてあるんすよぉ。   （rabi）

箱の中に隠れてー
（３０）（ユーザ名）が来たら飛び出す！
（６）うんうん中々にいいアイデアだ。
（２３）あっ。
（２６）えーと、聞いてないよね？                         （hapipiku）
```

rabi、hapipiku、maidSM、soine（リップクリームが失踪する）。トークが始まった瞬間に何かが起きている。
**サルバニに: ○（済）**。「あくび」「探し物」がこれ。店の中で起きることならまだ広げられる（工具を落とす、錠が勝手に開く音がする、ドアベルが鳴る）。

### S3. 問いかけて、自分の答えを言う

```
（愛称）は初めてお酒飲んだの、いつか覚えてるぅ？
あたしはねえ、二十歳の誕生日、日付変わった瞬間友達と一緒に飲んだんだあ。   （rabi）

（ユーザ名）、どこから来たカ？
もしかしたらワタシ、ソコ行った事あるかもヨ。
何を隠そうワタシ、趣味が旅行だからネ！                    （chinatown4649）
```

rabi、chinatown4649、hapipiku（PK戦やらなーい？）、Chocolate-box。問いの答えは待たずに、自分の話へ移る。ユーザについて何も決めつけずに巻き込める。
**サルバニに: ○**。voice の「ユーザについて決めつけない」が勧める「尋ねる形」とそのまま合う。

### S4. 豆知識を一つ、素の感想で終える

```
酔拳って実際に酔っ払うワケじゃないらしいネ。
世界一カラダ大事しない武術だと思ってたのにナー。
夢ない話ヨ。                                            （chinatown4649）
```

chinatown4649、AC_aoba（怪異）、Yumemi_1st（お菓子の作り方）、NotofThisWorld（海の生き物）、BadEnd_X_Searcher（童話）。知識は一つだけで、説明は一行。残りは感想。
**サルバニに: ○**。サルバニの長めの型との違いは、知識を積み上げずに一つで止めること。錠以外の雑学でもよい。

### S5. 商売の本音をばらす

```
ワタシ別におカネ一番のヒトじゃないのヨ？
このお店はほとんど道楽同然ネ。
それはそれとして、商売なんだから最大限儲けようと頑張るのは筋だと思うノ。
そういうワケだから（ユーザ名）、出来るだけでいいからいっぱい買ってッテ♪     （chinatown4649）

適当に来て、あたしがいなかったからって他のキャストと仲良くなったりしちゃダメだかんねえ。
……っていうと、大体のご主人様はあたしの出勤日にちゃ～んと来てくれるんだけどお。   （rabi）
```

chinatown4649、rabi、konno_chang（クーポンの手口に負ける）。客であるユーザに、営業の手の内を見せながら営業する。
**サルバニに: ○**。初回起動で決めた「愛想のいい商売人」がまだランダムトークに出ていない。預かりサービスや、おまけのしすぎ（どんぶり勘定）が材料になる。ただし、自分の隙を面白がって差し出す形（voice の×「おまけのしすぎ？　ヘヘ、何のことやら」）とは分ける。chinatown4649 は隙ではなく商売の理屈を、明るく言い切っている。

### S6. 土地の者として助言する

```
お客サン、ウチ来るならお昼すぎ辺りからにするといいヨ。
朝早くはネ……いないコトあるかもアル。
いや低血圧でネー。朝強くないのヨ、ワタシ……。            （chinatown4649）

このへんキャッチの人多いから、行き帰り気を付けてくださいよぉ？
……ウチは違うって言ってるじゃないすかぁ。                 （rabi）
```

chinatown4649、rabi。ユーザは外から来る客で、話し手はその街の者。助言の形で自分の隙や店の事情が出る。
**サルバニに: ○**。ユーザは伏原の店に通ってくる常連。向かいのお肉屋のような街の具体物が使える。

### S7. 第三者が割り込む

```
｜「「「姉ちゃん、あーーそーーぼーー！！」」」
｜帰れガキ共、接客中アル。
｜「えー！」「いいじゃん！」「どうせ何も売れないよ！」
（中略。子どもたちのベイゴマを５万で売ったと分かって）
｜「じゃあな姉ちゃん！」「またね！」「５万の女！！」
｜……５万の女は早急にやめさす必要があるネ……。
（３１０）お騒がせしたアル！ 目ぼしいノは見つかったカ？        （chinatown4649）
```

chinatown4649 だけ。ソロのゴーストが、\1 に「」付きで近所の人の声を出して寸劇にする。最後はユーザへの接客に戻る。
**サルバニに: △**。voice の「依頼主の出入りは書いてよい」「依頼主はその場にいても喋らない」と当たる。依頼主以外の近所の人（お肉屋、子ども、配達）なら喋らせられるかは決め直しが要る。長くなりやすいので、使うなら10行の上限内で。

### S8. ユーザの様子を \1 の地の文で書いて、それに返す

```
｜（悲しみ）（グゥ～……）は～……。お腹空いたぁ……。
｜物悲しい表情で薄い腹をさすっている。
何か食べるものを、と注文しようとして、彼女が待ったをかけた。
｜ありがたいっすけど、いらないっす～。                     （rabi）
```

rabi、SAMEKUJIRA（ユーザの仕事の独り言から始まる）、Dismember・KodamasReach（ユーザの内心を括弧で）。
**サルバニに: △**。サルバニの \1 はユーザの声なので形は使える。ただ、ユーザが何をしたかを書くと「ユーザについて決めつけない」とぶつかる。誰がやってもおかしくない所作（棚を眺める、錠を手に取る）に限る。

### S9. 定型ネタ

```
え～、ゲリラ豪雨とかけまして、ときめきと解きます。
その心は、局部が濡れます。                                 （HighColorMulti）
```

HighColorMulti（なぞかけ・小噺）。毎回同じ枠で中身だけ変える。キャラの芸そのものが型になっている。
**サルバニに: △**。サルバニに決まった芸はない。作るなら「今日の一錠」のような店の決まりごとになるが、講義に戻りやすい。

### S10. 情景や詩

mugen-en（旅先の情景描写だけの散文）、Mantodea・owl・vii（詩句）、yumenikki_2nd（不穏な断片）。人物より空気を出すゴーストの型。
**サルバニに: ×**。陽気な商売人の声と合わない。

### S11. ユーザへの好意

LuvandMe、SheIsNotMine、AbunaiMONAMOUR、Arianna、Mantodea、kaiyagura、ccc、Dismember。ユーザとの関係そのものが主題のゴーストに多い。
**サルバニに: ×**。voice の「気に入った常連」にあるとおり、好意をまっすぐ言わせると安くなる。甘い好意の×例もある。

### 付属: 返事の選択肢

toutotu_world と zizezo はトークの最後にユーザの一言（「でもやっぱり羨ましい」）を選ばせる。kaiyagura と Katari は分岐する選択肢を付ける。型というより、どの型にも付けられる仕掛け。サルバニのエンジンには BranchTalk があるので付けられる。

## コンビの型

### C1. ボケとツッコミ

```
ボク、ニンジャの修行をしてるんだ。
｜（３）……いきなり何？
｜修行すれば、分裂したり火を噴いたり出来るんでしょ？
｜マンガの読みすぎ……                                      （sagiri_tama）
```

sagiri_tama、suisou、room08。片方が言い出し、もう片方が冷める。

### C2. 語りに相方が補足し、崩す

```
吸血鬼の弱点というのは、伝承や宗教によるところが多いのだよな。
つまりは本質的には、無敵ということだ！
｜そんなことありませんよー。心臓に杭を打たれたら死んじゃいますもん。
｜誰だってそうだっつーの。                                  （fake_vamp）
```

room08（医学の蘊蓄に看護師が補足と毒舌）、fake_vamp。ソロの S4 に聞き手が付いたもの。

### C3. 相方に尋ねて、好みの違いを見せる

fake_vamp（敷布団派とベッド派）、ToothandNail（フィオの服の趣味）、fulloflove_desuwa。

### C4. 同居の生活の一場面

```
｜今日ご飯どうする？
｜次自炊する担当は？ ……私か。
（中略）
｜……（ユーザ名）さんは何食べたいですか？
｜ほれ見たことか。                                         （Walk_with_You）
```

Walk_with_You、suisou。ユーザも同居人として話に入れる。

### C5. ソロ回を別に持つ

ToothandNail は掛け合いの束のほかに、片方だけが喋る束を持つ。twelfth_night と appletree はほぼ独り語りで、相方はたまにしか入らない。コンビでも、全部を掛け合いにはしていない。

### コンビの型をソロのサルバニに移すなら

サルバニの \1 はユーザなので、相方の役はユーザの短い返事になる。

- C1 は、ユーザに突っ込ませることになる。voice の「ユーザは押し切られる側。批評を加える役ではない」とぶつかるので使わない
- C2 と C3 は、ユーザの一言（「二本？」のような素の口語）を挟む形なら使える。ただし \1 は5行しかない
- C4 は、店の中の一場面として S2・S7 に近い形で使える

## サルバニへの使い方

調査のあと、ここに「S5・S6・S3 を試す」という推薦を書いていた。型を選んでからサルバニの設定を当てはめる書き方になるので、2026-10-06 に消した。いまの書き方は、2行・5行前後・8〜10行を混ぜた案を作者に選んでもらう形（[sarvani_voice.md](../../lore/sarvani_voice.md) の「長さは混ぜる」）。

型の一覧は、出した案が同じ作りに偏っていないかを後から見比べるときにだけ使う。

chinatown4649 は朝が弱い、旅行が趣味という隙までサルバニと重なる。言い回しや具体的なネタを移さないこと（「低血圧でお昼すぎから」「どこから来たカ、ソコ行ったことあるかも」はそのまま書かない）。
