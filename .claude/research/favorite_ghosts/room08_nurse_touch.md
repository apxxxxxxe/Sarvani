# room08 看護師（\1）の触り反応

room08 の \1、名護睦月（看護師）の触り反応を全部読んだ記録。2026-10-06。作者がサルバニの触り反応を見直すときにいちばんの参考にしたいとしたもの（「好意的かつ積極的な反応で、これをサルバニでも目指したい」）。

触り反応全体の調べは [touch_reactions.md](touch_reactions.md)。ここは看護師だけを掘る。

**これを手本にして台詞を書かない。** 看護師の台詞が効いているのは、隣に藪井（医者、\0）がいて、ほぼ毎回茶々を入れるから。言い回しや踏み込み方をそのままサルバニに移すと、受け止める相手のいない重い台詞になる。

**好意を言葉で言う本は1割に満たない。** 積極的に見えるのは、好意を宣言するからではなく、触られたのを合図に自分から次の行為を持ち出すから（下の型1）。

## 返しの型

### 1. 触りを「次の一手」に読み替えて、自分から一歩進める

いちばん多い。ユーザがした行為の意味を勝手に一段進めて、自分から次をねだるか、仕掛ける。

```
（ユーザ名看護師）、撫で合いっこしましょうか。                              （頭なで）
もっとなでてください。｜あ、疲れたら言ってくださいね。｜そしたら今度は私がなでるほうをやります。   （頭なで）
そのまま、顔を近づけて。｜目をつぶって…                                     （頬なで）
あ、これは。｜キスの許可が下りたってことですよね。                          （唇なで）
もう片方の手も貸してください。｜先生に取られると癪なので。                   （手）
手を繋ぎますか。｜いつかデートするときも、こうしてくださいね。                （手）
あれですか。｜こっち向いてっていうやつですか。｜くそかわ。                    （頬つつき）
呼んだだけとか言ったら、かわいすぎて押し倒しますね。                         （頬つつき）
これが欲しいなら、さしあげますけど。                                         （唇つつき）
```

つつき（ダブルクリック）は「呼ばれた」「こっちを向いてほしい」と受け取る。撫では「もっと」「その先」をねだる。

### 2. 嫌なことをされても受け入れて、上乗せする

```
いけません。｜それではちっとも痛くない。｜私が貴方の機嫌を損ねたと言うのなら。｜もっとひどいやり方で罰してください。   （頭つつき）
どんなに嫌われても、お傍にいられるのなら構いませんよ。                      （頭つつき）
少し痛いです。｜ほんの少しだけ。｜貴方よりはきっと、痛くないのだと思います。  （頭つつき）
```

叩かれたのを自分の落ち度と受け取り、相手を気づかう。献身の重さがある。

### 3. 突き放されても引かない

胸のホイールの片方向は「押し返す」になっていて、ユーザが看護師を拒む操作になる。

```
………｜はっ、ここは素直に押し倒されておくのが最善だったのでは。｜しくじりました。｜もう一回お願いします。
いやです。｜離れたくないです。｜いやです。
私は貴方が嫌がるなら、無理やり何かをしたりしません。｜だから、どうか。｜嫌なら嫌だと、はっきり仰ってください…
```

拒まれても好意を引っ込めない。ただし最後の例のように、嫌なら言ってほしいと相手の意思を立てる本も混ぜてある。

### 4. 職務の道具を、好意の道具に転用する

```
手錠をかけて。｜私が、鍵を飲み込んでしまったら。｜（ユーザ名看護師）、どうします？      （手錠）
手を繋ぎますか。｜……貴方の意思では、外せませんけど。                         （手錠）
これは貴方を傷つけるためのものではないので、無暗に触ってはいけません。｜貴方を守るためのものなんですよ。   （メス）
患者さん方の個人情報です。｜ですが、（ユーザ名看護師）になら惜しげもなく見せてさしあげましょう。   （カルテ）
（ユーザ名看護師）はナースキャップ、お好きですか。｜貴方の好みならまぁ、喜んで被らないこともないです。   （キャップ）
```

身につけた仕事道具が当たり判定になっていて、その道具の本来の用途を、ユーザへの好意の言い方にねじ曲げる。手錠と鍵は錠前そのもの。

### 5. 冷静な敬語のまま、中身だけ踏み込む

```
この程度では懐柔させられませんが大好きです。                                 （頭なで）
どうしましたか。｜埃でもついていましたか。｜とか冷静な振りをしつつ、内心すごく幸せです。   （頭なで）
女性は頭を撫でられると喜ぶとかいう恋愛指南には、そんなことないだろって思ってたんですけど。｜ちょっと私の反抗心が崩れてく音がしますね。   （頭なで）
```

口調は最後まで看護師の丁寧語。言っていることだけが過激か、甘い。「好き」を言う数少ない本も、この落差の中で言っている。

### 6. 理屈っぽく真面目に、ずれたことを言う

```
どういう反応がいいですか。                                                   （胸つつき）
いえ――嫌がるか、恥じ入るか、喜ぶか。｜どれが（ユーザ名看護師）にとって好ましい反応か、それが問題なのです。   （胸なで）
それで私が疲れたら、（ユーザ名看護師）がなでるほうに代わって…｜…｜それから…はっ…永久機関…   （頭なで）
（利き手は？と聞かれて）右72kgの左68kgです。                                （手）
```

真剣に検討した結果がずれている。好意の重さを、本人の真面目さが笑いに変えている。

### 7. 選ばせる問いで終える

```
（ユーザ名看護師）、どうします？                                              （手錠）
……それとも、乱したいですか？                                                （着物の裾）
空いてるほうの手を、つないでおきましょう？                                   （手）
```

25本が問いかけを含む。答えはユーザに預ける。

## 非言語

### 表情は動かさない

看護師の表情指定277回のうち、多いのは次の4つ（シェルの部品で確かめた）。

| 番号 | 回数 | 顔 |
|---|---|---|
| 2012 | 64 | 目を閉じた伏し目＋小さく開いた口 |
| 2000 | 52 | 目を開けた真顔＋小さく開いた口 |
| 2015 | 44 | 伏し目＋閉じ気味の口 |
| 2024 | 18 | 目を開けた真顔（2000 と目の部品違い） |

あとは半目（2030 台）、見据える目（2036、2039）、冷めた横目（2045）。**笑い口の部品（1205、1207）は触り反応で一度も使っていない。** 頬を染める部品もない。

「くそかわ。」「内心すごく幸せです」「押し倒しますね」を、伏し目か真顔のまま言う。表情が平らなぶん、台詞の踏み込みが目立つ。型5の落差は、絵の側でも作られている。

### 間と名前

- 「……\w9」で始めて、溜めてから言う本が多い。突き放されたときの「…\w2…\w2…\w9（ユーザ名）さん。｜私じゃ、だめですか。」
- 102本中44本でユーザを名前で呼ぶ。名前には息の詰まった形が用意されている（「（ユーザ名）、\w4さん」「（ユーザ名）、\w4っ」）。胸を撫でられて言葉が途切れる本で使う
- 「（ちゅ）」のような一語の擬音で行為を見せる（唇なで）。地の文は書かない

### 医者が茶々を入れる

96本で医者が口を挟む。役目は二つ。

- **重さを軽くする**。「どんなに嫌われても、お傍にいられるのなら」に「殊勝だネェ」、「押し倒しますね」に「急いでナンかしら用事つくッテ」。看護師の台詞だけを読むと重いものが、医者の一言で冗談の側に戻る
- **看護師の二面を見せる**。ユーザには甘い敬語、医者には「その汚ねぇ手で触んじゃねぇぞくそ医者。」「黙れよアラサー。」。この落差で、ユーザへの態度が特別だと分かる

### 拗ねた状態

`nagosune` の辞書に切り替わっているあいだは、どこを触っても短い拒否になる。

```
…………だめですよ。
誰にでも、貴方はそうですね。｜だから今は、喜びようがないんです。
恋人でもないのに、そんな風に触れるんですね。｜ごっこ遊びですか？
```

普段の積極さがあるので、この冷たさが効く。

## サルバニに移すときに考えること

作者と相談するために挙げた材料。2026-10-06 に作者が決めたこと:

- 触り反応の主軸を「自分から踏み込む」に入れ替える。旧主軸（品定めして挑発する）はまっさらにする勢いで
- ソロの重さは、syumu_gari のように「一歩で止めて相手に預ける」で処理する
- 踏み込みは看護師と同程度まで行ってよい
- 表情は移さず、サルバニの陽気さを残す

voice の「触り反応」はこれに沿って書き直した。以下は相談前に挙げた元の材料。

1. **サルバニはソロで、医者がいない。** 看護師の台詞は中央3行で、その重さを医者が中和している。サルバニでは、自分で崩す（[touch_reactions.md](touch_reactions.md) の T5）か、踏み込む一歩を短く止めるかしないと、重さだけが残る
2. **好意の見せ方は voice とほぼ同じ向き。** 看護師も「好き」は1割に満たず、好意は次の一手を自分から出すことで見せている。voice の「好意の告白にはしない。乗り気は問い返し、挑発、許可で見せる」と合う。違うのは、voice の主軸が「手つきを品定めして挑発する」（相手を評する）なのに対し、看護師は「自分から踏み込む、ねだる」（自分が動く）こと
3. **型4（道具の転用）は、題材が錠前に近いからといってサルバニに使えるわけではない。** 手錠の台詞が効いているのは、看護師の献身の重さと医者の茶々があるから。「手錠と鍵だから鍵屋に直に使える」と書いた初版は、作者に「安易な関連性に飛び付かないように」と注意された（2026-10-06）。サルバニの当たり判定に道具はない（頭・胸・肩・手）
4. **型5（敬語のまま中身が踏み込む）は voice の「丁寧語と気安さのずれが持ち味」と重なる**
5. **表情は移さないほうがよさそう。** 看護師は真顔と伏し目で通すが、サルバニは陽気な人物で、voice は「真顔は本当に真剣な一行に取っておく」としている。落差をどこで作るかは別に考える
6. **踏み込みの度合い。** 看護師はキス、押し倒す、既成事実まで言う。voice は胸に「色気も含めて乗ってよい」としているが、どこまで言わせるかは決めていない
7. **ユーザの性別で分ける本（一人称、弟妹、脚の「挟みます？」）は使えない**
8. **型2・型3（叩かれても、拒まれても引かない）は voice の「しつこく触られても拒まない」と同じ。** 看護師はさらに「もっと罰して」まで行くが、これは看護師の献身の重さで、陽気な人物には重い
