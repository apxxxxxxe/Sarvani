## 何を数えたか

## 何を尋ねさせているか

35体のうち、その主題の問いを1つ以上持つ数。語の一致で判定したので目安。

表に出ない主題で、どの一覧にもあるもの:

- **人物の設定や職能にじかに当たる問い。** 「瓦何枚まで割れる？」（空手少女の hinakura）、「寝る時尻尾の矢はどうしている？」（miyako）、「電子レンジは使えるの？」（Lakritze）。プロフィール系より面白い答えになっていることが多い。
- **疑問文でない選択肢**は、ユーザが自分から何か言う場所になっている。触り反応やコミュニケートと役目が重なる。

選択肢の文言の書き方は2通りある。ユーザの口調で書くもの（hinakura「友達いるの？」、tokyolt_「におい嗅いでいい？」）と、主題の名前だけを書くもの（vanishing「ヘレナの職業」、iron_dream「栄子の階級は？」）。後者はほぼ寄せられた質問の回答集で、元の文面は答えの中で読み上げる。

## 一覧の作り

1. **作者の想定問を固定で並べる。** hinakura、Lakritze、tokyolt_、miyako、hutago など。いちばん多い。
2. **寄せられた質問の回答集。** freak_scene、iron_dream、vanishing、foxeye、butterfly、bro.M。答えの頭で質問の文面を読み上げる（freak_scene: `「なんとお呼びすればいいですか？」か。…案外、難しい質問じゃな`）。主題がばらけ、性的な問いや冗談半分の問いが増える。
3. **関係が進むと質問が増える。** miyako は好感度の低・中・高で選択肢が増える（高で「二人の一番行きたい場所は？」）。family_kit も段階で増える。Lakritze は名前を教わると一覧が広がる。
4. **同じ枠を聞くたびに一段深くなる。** BTHver.5 は、一覧の1行が聞くたびに差し替わる。「変わった名前だね」→「日本人じゃないの?」→「本名は?」と進み、3回目で「アタシ、自分が何者なのか、覚えてないんだ」に行き着く。何度か聞いてきたユーザにだけ重い話を出す。サルバニの BranchTalk はその場で選ぶ分岐なので、これとは仕組みが違う。
5. **毎回ランダムに数問だけ出す。** 6_v（「質問リロード」）、rereregion、musuwaka（「質問シャッフル」）。6_v は同じ質問に複数の答えがあり、好感度で切り替わる。

## 答えのどこが面白いか

回答の本文まで読んだのは hinakura、BTHver.5、Lakritze、6_v、freak_scene、miyako、kanade_2nd。

- **ありふれた問いに、その人物ならではの理由で答える。** hinakura に「どんな曲をよく聴く？」と聞くと「音楽…聴かないわね…興味ないし…耳を塞ぐと不便だし」。耳を塞ぎたくないという理由から、武道家の用心深さが出る。プロフィール系の問いは問いとしては退屈だが、答えの理由で人物を見せる入口になる。
- **尋ね方に反応する。** hinakura は「友達いるの？」に「えげつない切り口ね」と返す。Lakritze は「電子レンジは使えるの？」に「身近に電子レンジ使えないヒトでも居るの？」と返し、間を置いて「……なんで私を見るのかな」。質問した側の思惑を読み返すので、メニューを押しただけでも会話をした手応えが残る。
- **問いの無作法を咎め、関係で答えを変える。** Lakritze（バーテンダー）に初対面で連絡先を聞くと「初対面みたいな女の子にそんなこと聞いちゃダメだよ？ ウチはそういう店じゃないんだから」と叱られ、来店回数が5減る。通ってから聞くと、店の名刺の裏にアドレスを書いて「みんなには秘密だよ？」。店の人と客の距離を、質問のメニューで演じている。
- **長さはランダムトークより短め。** miyako は3〜4行、Lakritze は2〜6行、6_v は1行のものも多い。長くなるのは BTHver.5 の深い段と、設定の説明に当たる問い。kanade_2nd の「5つの質問」は、見出しに問いを掲げてから答える読み物の体裁。

## 道具

`.claude/research/tools/` に置いた。`PYTHONIOENCODING=utf-8` を付けて動かす。

```
G='C:\Users\user1\Ukagaka\ssp\ghost'
python .claude/research/tools/extract_questions.py "$G" .claude/research/ssp_ghosts/questions/questions.tsv   # 質問メニューらしき節の選択肢を抜き出す（ゴースト名を足せば絞れる）
python .claude/research/tools/question_themes.py .claude/research/ssp_ghosts/questions/questions.tsv          # 質問一覧を持つゴーストと、主題ごとの体数
python .claude/research/tools/satori_section.py "$G/Lakritze" '^＊質問(レンジ|連絡先)'                       # 回答の節を読む
```

`questions/` は他作者の著作物の抜き出しなので gitignore してある。

`extract_questions.py` は、話しかけや設定のメニューも拾う。質問メニューへの絞り込みは `question_themes.py` が見出しと辞書のファイル名で行う。回答を読むときは、まずメニュー側の `\q[ラベル,ID]` で ID を確かめる。ラベルと節の名前が違うゴーストが多い（miyako の「好きな食べ物は何？」は `＊好きな食い物`）。
